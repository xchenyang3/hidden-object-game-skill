# 儿童绘本视觉寻找游戏

把插画做成可玩的视觉谜题。优先沿用用户提供的画稿与已经认可的审美，保持章节和内容形式灵活。

## 先确定游戏类型

- **隐藏物品**：在一张复杂场景里寻找指定物品。用户说“按这次派对图”“找电池、芯片”等，默认此类型。
- **两图找不同**：两张构图相同的图，只有明确列出的局部差异。用户明确说“两张”“几处不同”时选此类型。
- 若“找茬”没有上下文且会影响交付，只问这一项；其他缺失信息可提出暂定方案并开始。不要混淆两类答案。

## 输入与默认值

从当前需求提取：年龄、场景、主题、风格、目标物品或差异数量、难度、画幅、预期印刷尺寸、交付范围和参考图。不用让用户填长表。

未指定时建议：小学中高年级，横向跨页，黑白线稿，中等难度，隐藏物品4–6种各1个；此为可改默认，不是出版标准。没有指定目标时，先选与主题相关且轮廓可区分的物品。不要为了凑数量加入难以辨认的抽象符号。

智啾啾只在用户要求或本书相关任务中沿用；欢欢与智啾啾是同一NPC，不得拆成两个角色。无现成形象参考时，不擅自锁定其外形。其他作品不自动加入该角色。

## 工具与参考

使用当前可用的原生图像生成/编辑工具；通常发现并调用 image_gen。编辑本地图像前先查看目标图。新场景用生成，保留构图的优化和找不同B图用编辑。原生工具不可用时如实说明；不要自动切换付费API或声称生成完成。

- 需要生成、难度修订或答案图提示词时，按任务阅读 [references/prompts.md](references/prompts.md) 的对应段落。
- 用户说“像那张派对图”时，阅读 [references/party-case.md](references/party-case.md)，按需要查看两张示例图。示例是用户认可的方向，不是每次必须套用的场景或角色。

## 隐藏物品的制作

1. 在生成前建立目标清单：名称、数量、可辨认特征、候选藏法。例如电池应保留端帽/接点，芯片保留四边引脚，麦克风保留网罩与柄。
2. 先设计完整可信的场景，让人物各有动作、空间有前中后层次。物品隐藏在场景的线条中，不摆成展示柜。
3. 把难度放在**视觉伪装**上：旋转、轮廓借用、局部遮挡、相似邻居、花纹融合及分散位置。目标与环境使用相同线粗，不留下显眼空白或粗边框。
4. 每个目标至少保留足以辨认的结构；不能只剩一个普通圆圈，也不能把餐巾硬说成电池。不依靠微小尺寸或满页乱线制造难度。
5. 在学生图中不加答案圈、箭头或位置提示。找物清单可单独呈现；仅在用户需要时安排页内图标栏。
6. 查看实际生成图，逐个找到目标并检查数量、辨识度、误认对象及重复物。提示词要求“唯一”不等于图中真的唯一。发现缺失或歧义，定点修订并复查。
7. 确认游戏图后，按实际位置制作答案，不按预设藏匿位置猜答案。

## 两图找不同的制作

1. 生成或确认A图后，以A为编辑目标制作B，不分别生成两张场景。
2. 预先列出差异，例如少一枚纽扣、杯柄方向改变、叶片数量变化；差异适合黑白印刷，不能把单纯色差算作黑白题差异。
3. 每一差异局限于一个清楚区域。保持其他构图、人物、比例和细节不变；禁止用全面重绘增加未计入差异。
4. 对照实际A/B逐项检查计划差异和意外变化。生成编辑可能造成额外差异；不能直接保证“恰好N处”。
5. 出现明显额外差异时修订；未完成全面核对的只能称试样，不能称已验证的N处找不同。
6. 答案记录每处在A/B中的位置与变化，不沿用隐藏物品的物件清单。

## 答案与检验记录

以最终游戏图为唯一来源。答案图使用同一图像编辑，标记薄圈与序号，避免遮住目标；找不同可在A/B两侧对应标记。核对标记对应的实际轮廓，并检查编辑是否改变了谜面。若不能保持一致，应说明限制并继续修订，不能用看似相似的图冒充精确答案。

批量生产或用户要求文件时，附简短清单：
- 图片编号、游戏类型、最终文件、版本。
- 目标/差异名称、应有数量、实际确认数量。
- 已确认的归一化边界框 [x/W, y/H, width/W, height/H]，保留实际图像宽高；边界框只在目视确认后填写。
- 状态：confirmed / ambiguous / missing / duplicate / unchecked。
- 修改谜面后答案同步到相同版本；不得混用旧图坐标。

检查整体场景可读、目标形态可信、寻找难度合理、答案匹配，以及计划印刷尺寸下的线条和目标大小。若只检查屏幕显示，应称屏幕试样；没有学生试玩或印刷检查，不声称已经试玩、适龄验证或可直接付印。

## 难度调节与系列生产

容易：目标轮廓完整、遮挡较少，使用相对简洁的邻域。
中等：加入旋转、相似轮廓和适量遮挡，但关键特征清楚。
困难：更多共享轮廓和花纹融合、位置分散；依然能够辨认。目标宽度占整图1.5%–3%只可作为本次案例的试验起点，必须结合成品尺寸检查，不能固定套用。

系列可更换生日会、集市、博物馆、海底探险或太空站等场景；按用户范围逐张生产，不擅自批量生成。保留用户批准的线条与人物设定，藏匿位置随场景改变，避免总在同样角落。

明显问题最多进行两轮有针对性的修订；仍无法达标，说明具体未解决项，并提供简化场景、减少目标或分两次生成的选择。用户要求继续时可再调整，不无限自动重试。

## 交付方式

默认制作一张学生图及对应答案图；用户只要谜面或探索样图时遵从其范围。先展示学生图，答案随后单独明确标注，避免一开始剧透。文字简短，不把生产提示词、审核表或坐标印进儿童画面。

图片预览可以留在原生工具返回的位置；用于书稿或批量文件时在有写权限的交付目录保存版本化副本。不要覆盖原稿。准确区分“已生成”“已核对”“待试玩”“印刷候选”。需要导出PDF、裁切或改成特定印制规格时再处理，不默认替用户定开本与DPI。
