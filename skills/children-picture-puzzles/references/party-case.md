# 本次派对图的可复用经验

## 用户认可的方向

本案例来自《玩游戏，学AI》的创作讨论。用户要复杂精细的儿童游戏书黑白线稿，热闹派对里藏电池、芯片、麦克风等。第一次图像把目标直接摆在桌面、墙上、椅背，过于明显。第二轮将物品缩小、旋转并融入环境，用户明确认可，要求总结成技能。

本案例是**隐藏物品图**，并不是两张图比较差异。用户口头说“找茬”时应结合上下文判断。

## 实际画面与经验

- 场景：温室与庭院派对，儿童、友好机器人、花草、长桌、礼物和乐器。
- 风格：白底黑色轮廓线，细节丰富，可寻找也可涂色，无大块灰度渲染。
- 目标：电池、芯片、麦克风、电路板、相机、齿轮。
- 第一版问题：目标大、独立、轮廓过清楚；如摄影机直接悬挂、芯片画在礼盒正面、电路板拿在手中。
- 第二版方法：先清掉显眼目标，再融入餐巾褶皱、墙砖、吊篮枝叶、蛋糕装饰、前景花丛和椅腿附近的图案。注意：位置由生成模型实际决定，要看图后重新记录。
- 答案序号：1电池、2芯片、3麦克风、4电路板、5相机、6齿轮。

## 不能继承为固定规则的细节

场景不限花园派对，目标不限电子元件，人物不必是这一组。不要把六件物品、横版或黑白强制成所有作品的规范。

本次示例也揭示了一个边界：隐藏过度会使物品变得像普通装饰；尤其电池的接点和外形需要放大检查。用户认可整体方向，不能代替逐件核验与真实试玩。答案图由生成编辑制作，不能自动认为除标记外与原图逐像素一致。
